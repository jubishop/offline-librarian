### F1: An unfinished from-scratch rebuild drops vectors  (fixed)

- **severity:** Warning
- **status:** fixed
- **location:** librarian/meaning.py:259
- **scope:** in-diff
- **concern:** a new `library.sqlite` has no `builds` row until its first build finishes, so `_builds` returned None, which differed from the store's checked count, and a pass during the build dropped the vectors of every source not built yet (Wikipedia's are about three days of embedding), contrary to the guard the PR and design describe

### F4: A build's finish can go unrecorded  (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** librarian/build.py:195
- **scope:** in-diff
- **concern:** a build interrupted during its long index optimize records no id and its rerun changes nothing, and a no-op build on a pre-change library creates an empty `meta` table, so the vectors left unused stay until a later build changes the library
- **resolution:** it errs toward keeping vectors and recovers at the next build that changes something; the cost is disk and slightly slower searches for up to a month, which doesn't justify extra state or a fault-injection test
